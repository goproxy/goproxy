# Security policy

## Reporting a vulnerability

To report a security vulnerability in Goproxy or the official `ghcr.io/goproxy/goproxy` container image, open the
[repository's security page](https://github.com/goproxy/goproxy/security) and select **Report a vulnerability**.

Please include the relevant details below.

- The affected Goproxy version or commit, or the container image tag or digest
- The configuration and steps needed to reproduce the issue
- The observed behavior and its security impact

Please keep vulnerability details in the private report while we investigate and coordinate disclosure.
